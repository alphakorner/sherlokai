    Méthode, sources et limites

    Comment l'app classe un commerce

    • Sans site : aucune URL dans OpenStreetMap et aucun site trouvé en testant nomducommerce.fr / .com.
    • Réseau social : l'URL déclarée mène à Facebook, Instagram, Linktree, une fiche Google, TheFork, Planity…
    • Site HS : le site ne répond pas, ou c'est un site gratuit (Wix, Jimdo…).
    • Site pro : un domaine propre qui répond.
    • Fermé : établissement fermé à l'INSEE, indice dans OpenStreetMap, « définitivement fermé » sur Google (avec clé), ou marqué par toi.

    Fiabilité

    OpenStreetMap est tenu par des bénévoles : un champ site vide veut dire « non renseigné », pas forcément « pas de site ». Vérifie toujours d'un clic sur Google avant d'appeler. Les registres INSEE ont parfois quelques mois de retard sur les fermetures réelles.

    Sources et API utilisées

    • OpenStreetMap via Overpass et Nominatim (licence ODbL, attribution obligatoire).
    • API Recherche d'entreprises (recherche-entreprises.api.gouv.fr) : données INSEE et RNE, gratuites et ouvertes.
    • API BODACC (DILA) : annonces commerciales officielles.
    • API Découpage administratif (geo.api.gouv.fr) : population et codes postaux.
    • Fonds de carte Esri (Leaflet) et itinéraires OSRM.
    • Google Places, uniquement si tu renseignes ta propre clé.

    Cadre légal (France)

    La prospection B2B d'un commerçant pour son activité professionnelle est permise au titre de l'intérêt légitime (RGPD). Indique d'où viennent tes données et respecte toute demande d'opposition. Les informations des dirigeants proviennent du registre public ; utilise-les seulement pour ta prospection professionnelle.
